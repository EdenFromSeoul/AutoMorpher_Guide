# Texture Studio 가이드 제작 계획과 문서 양식

작성일: 2026-10-23 · 대상 화면: Kisetter 3.5.0 / Texture Studio (Early Access)

## 제작 순서

1. 현재 표시되는 기능과 가이드 범위를 정리한다.
2. 아래 공통 문서 양식과 촬영 목록을 확정한다.
3. 참고 영상을 확인하고 VRCLabProject에서 실제 사용 화면을 촬영한다.
4. 촬영 결과를 넣어 가이드 페이지를 완성하고 로컬 화면에서 검수한다.

## 기능 목록과 가이드 구성

| 장 | 기능 | 설명할 작업 | 이미지 |
| --- | --- | --- | --- |
| 1. 편집 준비 | Root에서 읽기, Mesh 드래그, Texture 탭 | Texture Studio 열기 → 대상 등록 → Main Mesh 선택 | Scene + Kisetter, 의상/헤어 각각 |
| 2. 여러 Mesh와 UV 선택 | 편집 중, 동시 조정, On/Off, UV Island 클릭·박스, 전체 선택·해제 | 선택할 범위와 실제 오브젝트 표시 구분. Hair 네 Mesh 동시 편집. Body의 피부·눈동자 부분 선택 | 헤어 대상 목록, Body 선택 예시 |
| 3. 색상과 톤 | 색상 지정, 색상 시프트, 선명도/채도, 밝기·대비·감마, HEX | 영역 선택 → 색상 지정 또는 시프트 → 톤 조정 → Scene 확인 | 의상/헤어 변경 전후 후보 |
| 4. 그라데이션 | Gradient 색상 키, UV에서 그리기, 그리기 종료 | 색상 지정 → 시작점에서 끝점으로 드래그 → 종료 → Scene 확인 | 의상/헤어 각각 UV 선과 결과 |
| 5. 색상 자동 조정 | 기준점, Target 참조점, Texture만/Material 설정 포함 | 선택 UV 확인 → 기준점/별도 Mesh 참조점 선택 → 자동 조정 → 결과 확인 | 의상/헤어 각각 가능한 참조 예시 |
| 6. 결과 확인과 수정 | Texture 표시/Material 미리보기, 편집 결과 미리보기, 이력, 되돌리기 | 원본 비교, Undo/Redo, Mesh별·전체 복원 차이 | UI 중심 |
| 7. 저장 | 새 Material/기존 Material, 폴더, 접미사, 저장 후 계속/종료 | 저장 옵션 선택 → PNG·Material 저장 방식 이해 | 저장 UI 중심 |

소스에만 남아 있는 오버레이, Mask/AO/Normal/Face SDF 생성, 기존 자동 컬러 매칭 패널 등 현재 화면에서 제공하지 않는 기능은 이 가이드에 포함하지 않는다. 현재 표시되는 `色の自動調整` 탭은 포함한다.

## 페이지 구성

- 메인 `texture-studio`: 편집 준비, Mesh·UV 선택, 세 편집 기능의 짧은 소개와 수정 전·후 비교, 미리보기·복원·저장.
- 하위 `texture-studio-color-adjustment`: 색조 지정·이동, 톤 조정, 의상·헤어 비교 예시.
- 하위 `texture-studio-gradient`: 그리기 순서, 의상·헤어 예시, UV 방향과 편집 이력 설명.
- 하위 `texture-studio-auto-color`: 기준점 선택, 조정 방식, 의상·헤어 예시, 결과 확인.
- 세 하위 문서는 `parent: "texture-studio"`를 사용하며 한국어·일본어·영어를 함께 제공한다. 메인 비교에는 색상·자동 조정의 의상 예시와 그라데이션의 헤어 예시를 사용한다.

## 촬영 기준

- 프로젝트: VRCLabProject (열린 Unity 창에서 프로젝트명 확인).
- 촬영 언어: Japanese. 본문의 버튼·항목 이름은 각 페이지의 한국어·일본어·영어 UI와 일치시킨다. 한국어·영어 본문에는 일본어 버튼 이름을 병기하지 않는다.
- 구도: Scene 왼쪽, Kisetter 오른쪽. UI 설명만 필요한 경우 Kisetter만 사용한다.
- Unity를 최소화하거나 창 크기·배치를 변경하지 않는다. 기존 Scene 구도를 유지한다.
- 의상: `Milfy_Ivory/UV1_Onepiece_Outer`.
- 헤어: `Hair_Front`, `Hair_Head`, `Hair_Side`, `Hair_Twintails`.
- 피부·눈동자: `Body`. Texture 탭과 UV 영역을 확인하고 필요한 부분만 선택한다.
- 사용자가 미리 할당한 Mesh를 사용한다. 원본 Scene과 Asset을 저장·덮어쓰지 않고, 촬영용 변경은 추적한다.
- 의상과 헤어 후보를 모두 보관하고 기능별로 나란히 비교할 수 있게 제시한다.
- 이미지에는 실제 UI와 결과를 사용한다. 자르기·용량 최적화만 수행하며 UI나 색상 결과를 합성하지 않는다.

## 기능별 문서 양식

```markdown
## [번호] 기능 이름

이 기능으로 할 수 있는 작업을 한두 문장으로 설명합니다.

### 사용 방법

1. 편집할 Mesh와 Texture 탭을 선택합니다.
2. 적용할 UV 영역을 선택합니다.
3. **해당 페이지 언어의 실제 버튼 이름**을 누르고 값을 조정합니다.
4. Scene에서 결과를 확인합니다.

### 사용 예시

의상: UV1_Onepiece_Outer — 목적과 결과.
[Scene + Kisetter 이미지]

헤어: Hair_Front / Hair_Head / Hair_Side / Hair_Twintails — 목적과 결과.
[Scene + Kisetter 이미지]

필요한 경우 Body의 피부 또는 눈동자 부분 선택 예시를 추가합니다.

### 확인할 점

선택 범위, 미리보기와 저장의 차이 등 이 작업에 직접 필요한 내용을 설명합니다.
```

- 한국어·일본어·영어 문서: 각각 7개 장, 이미지 19장. 이미지와 내부 링크·목차 앵커 검사 통과.
- 로컬 정적 빌드: 루트(`/`) 및 저장소 하위 경로(`/AutoMorpher_Guide`) 모두 통과. 언어별 탐색과 이미지 경로 확인.
- Chrome: 1440px, 390px, 320px 너비에서 가로 넘침 없음. 세 언어에서 이미지 로드, 목차 이동, 이미지 확대·닫기 확인. 브라우저 오류 없음.
- 데스크톱·모바일 캡처를 시각 검수했고 로컬 사진 비교 갤러리를 확인했다.

- 의상·헤어 선택용 비교 갤러리: `http://127.0.0.1:3001/review.html`.
- 두 서버는 `127.0.0.1`에만 바인딩한다. 커밋·푸시·GitHub Pages 업로드·외부 배포는 수행하지 않았다.

### 하위 페이지 분리 후 검수

- 각 언어의 메인 1개와 하위 3개, 총 12페이지를 구성했다. 기존 이미지 19장은 모두 유지했다.
- 메인의 세 기능은 짧은 설명, 수정 전·후 이미지 두 장, 상세 가이드 링크로 구성했다. 조작 순서와 의상·헤어 예시는 해당 하위 페이지에 있다.
- 루트 및 저장소 하위 경로의 로컬 정적 빌드 통과. 두 경로에서 12페이지의 이미지 참조 75개와 내부 링크 948개를 확인했다.
- Chrome에서 12페이지를 1440px·390px·320px로 확인했다. 하위 메뉴, 이미지 로드, 목차 이동, 메인에서 상세 페이지로 이동 후 돌아가기와 이미지 확대를 확인했다. 가로 넘침과 브라우저 오류가 없었다.
- 로컬 임시 페이지에만 반영했으며 커밋·푸시·외부 배포는 수행하지 않았다.

### 색조 이동 항목별 헤어 예시

- 사용자 지정에 따라 이번 항목별 예시는 헤어로 촬영했다. `Hair_Front`, `Hair_Head`, `Hair_Side`, `Hair_Twintails`를 함께 조정했다.
- 일본어 UI, 같은 Scene 구도와 Unity 창 배치를 유지했다. 기준 이미지 1장과 조절별 결과 5장을 추가해 이미지 파일은 총 25장이다.
- 색조 이동 +120°, 진하기 +70, 밝기 -25, 대비 +60, 감마 +60을 각각 독립적으로 적용했다. 다른 네 값은 항상 0이며, 각 결과를 촬영한 뒤 실행 취소해 기준 상태로 복귀했다. 의상에 시험 입력한 색조 +120°도 0으로 되돌렸다.
- 원본 Asset이나 Scene 저장은 실행하지 않았다. 이번 검증 범위는 UI 조작과 Scene 미리보기 촬영이다.
- 세 언어의 색상과 톤 조정 하위 페이지에 각 항목의 설명·입력값·변경 전후 이미지 쌍을 추가했다. 각 언어의 UI 명칭을 사용하고, 일본어 이미지 안내를 유지했다.
- 루트 및 저장소 하위 경로의 로컬 정적 빌드가 통과했다. 두 경로에서 12페이지의 이미지 참조 102개와 링크 978개를 확인했다.
- Chrome에서 12페이지 × 3개 너비(1440px·390px·320px)를 검사했다. 새 예시 5개, 이미지 로딩·확대, 목차·하위 페이지 이동을 확인했으며 가로 넘침과 브라우저 오류가 없었다.
- 로컬 임시 페이지에만 반영했다. 커밋·푸시·외부 배포는 수행하지 않았다.

### 그라데이션 팔레트 열기 안내

- 기존 VRCLab 일본어 UI 촬영 원본에서 그라데이션 탭·가로 색상 막대와 Gradient Editor 창을 잘라 안내 이미지를 구성했다. 실제 UI 문구는 유지하고 클릭 위치에 번호·테두리·화살표를 추가했다.
- 안내 문구는 한국어·일본어·영어로 각각 제작했다. 그라데이션 하위 페이지의 사용 방법 맨 위에 배치하고, 두 번째 단계에 탭 바로 아래 색상 막대가 팔레트를 여는 위치임을 명시했다.
- 기존 팔레트 단독 이미지가 새 안내 이미지 안에 포함되므로 페이지의 이미지 수는 3장을 유지했다. 이번 안내 제작에서는 Unity 화면을 조작하지 않았다.
- 루트·저장소 하위 경로의 정적 빌드와 링크·이미지 검사를 통과했다. 세 언어 × 3개 너비(1440px·390px·320px)에서 이미지 표시·확대와 가로 넘침을 확인했으며 브라우저 오류가 없었다. 로컬 미리보기에만 반영했다.

### 자동 색상 조정의 기준점·목표점 안내

- 기존 `outfit-auto-points.png`의 일본어 UI를 확대하고, 위쪽 `UVで選択`·`Meshで選択` 버튼은 파란색 ① 변환 기준점, 아래쪽 `Target Meshで選択` 버튼은 주황색 ② 변환 목표점으로 표시했다. 라벨·화살표·테두리를 사용해 편집할 Mesh의 점과 참조 색상을 가져올 점을 구분했다.
- 한국어·일본어·영어 안내 이미지를 각각 제작하고 각 언어의 UI 버튼 명칭을 사용했다. 세 언어의 자동 조정 하위 페이지 첫 장에 새 안내 이미지를 추가했으며, 기존 Scene + Kisetter 전체 화면도 유지했다. 이번 작업에서는 Unity를 조작하지 않았다.
- 원본 크롭 좌표 `(946, 461, 1345, 860)`와 생성 스크립트·매니페스트는 `outputs/texture-studio-vrclab-ja/`에 기록했다. 공개 이미지 크기는 1440 × 1000이다.
- 루트와 저장소 하위 경로의 정적 빌드를 통과했다. 각각 12페이지의 이미지 참조 105개와 내부 링크 978개를 확인했다.
- Chrome에서 세 언어 × 3개 너비(1440px·390px·320px)의 이미지 로딩·확대·닫기와 가로 넘침을 검사했다. 브라우저 오류는 없었으며 데스크톱·모바일 캡처를 시각 검수했다.
- 로컬 임시 미리보기에만 반영했다. 커밋·푸시·외부 배포는 수행하지 않았다. 이전에 요청한 헤어 확대 재촬영과 Scene 카메라 기록은 이 안내 이미지 작업의 완료 범위에 포함되지 않는다.
