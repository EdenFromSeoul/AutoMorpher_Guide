## Key Features

- Automatically match clothing bones to the target avatar
- Automatically deform clothing meshes to fit the target avatar
- Recalculate clothing weights for the target avatar
- Save fitting results as BlendShapes
- Make manual corrections by adjusting bones during fitting
- Add avatar BlendShapes to clothing

## Important Notes

- We recommend using an avatar in a clean state without other clothing attached.
- Adjust any Body Shrink-related parameters so that the avatar's Body is fully visible.
- Matching the Source Avatar and Target Avatar Foot Heel angles as closely as possible improves foot fitting quality.
- The avatar must be configured as a **Unity Avatar - Humanoid**.
- Gloves and hats can be adapted with Weighting. See [Tips for Improving Fit](../quality-tips/) for details.
- If the avatar is not detected automatically as Humanoid, or if it has multiple Body Meshes, disable automatic Body Mesh assignment and manually select the Body Skinned Mesh Renderer to use as the body-shape reference. Use **Mesh List** to choose the meshes that should be processed.

## Supported Avatars

- Human-like avatars configured as Unity Humanoid Avatars are supported.
- The avatar must have an unobscured torso Body Mesh that can be used as the fitting reference.
- Avatars are supported regardless of where they are distributed, including BOOTH, Gumroad, Jinxxy, VRoid, and original avatars.

## System Requirements
